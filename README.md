# 🧠 Healthcare Data Mining & Burnout Analysis

## Overview

This project explores mental health and burnout-related data in the technology industry using Data Mining and Machine Learning techniques.

The project covers different stages of data analysis, including preprocessing, exploratory data analysis, feature selection, clustering, and fuzzy logic.

## Project Objectives

* Explore factors related to mental health and burnout.
* Prepare and clean the dataset for analysis.
* Understand the data through visualizations and EDA.
* Select relevant features using a Genetic Algorithm.
* Group similar records using clustering techniques.
* Apply fuzzy logic as part of the analysis.
* Visualize and interpret the obtained results.

## Dataset

The project uses:

`mental_health_burnout_tech_2026.csv`

The dataset contains information related to employee mental health, burnout, and workplace factors.

## Data Preprocessing

The data preprocessing stage includes:

* Handling missing values
* Detecting outliers using the IQR method
* Encoding categorical variables
* Preparing the data for further analysis

## Feature Selection

A **Genetic Algorithm** is used for feature selection.

The selected features are compared with the baseline feature set to examine the effect of feature selection on the analysis.

## Clustering

### K-Medoids

K-Medoids is used to divide the data into groups of similar records.

### Hierarchical Clustering

Hierarchical clustering is used to examine the structure of the data and visualize relationships between groups.

## Fuzzy Logic

The project also includes fuzzy logic concepts as part of the data mining analysis.

## Results

The project provides:

* Exploratory analysis of the dataset
* Visualizations of important patterns and relationships
* Selected features using a Genetic Algorithm
* Clustering results using K-Medoids and Hierarchical Clustering
* Fuzzy logic analysis
